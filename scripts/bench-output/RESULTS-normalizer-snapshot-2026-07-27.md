# Снапшот замен нормализатора на продовом корпусе

Дата: 2026-07-27. Версия конвейера: `n1` (HallucinationFilter + LexiconNormalizer).

**Что это.** Полный перечень замен, которые `LexiconNormalizer` делает на корпусе
надиктованной речи владельца (1096 записей, 90 136 слов). Снапшот коммитится, чтобы
любое изменение словаря всплывало диффом на ревью: метрика на `eval-ru` этого не ловит,
потому что её подсчёт collateral damage приводит текст к нижнему регистру и вырезает
пунктуацию — то есть слепа к части эффектов.

**Приватность.** Здесь только агрегаты: исходная форма, замена, количество. Ни одной
строки контекста — корпус состоит из личной рабочей речи, а репозиторий публичный.
Сами словоформы и их частоты уже опубликованы в документе конвенции.

**Как воспроизвести** (только на машине владельца — корпус локальный, в git его нет):

```bash
VOICETYPE_JSONL_IN=<corpus.jsonl> VOICETYPE_JSONL_OUT=<out.jsonl> \
  swift test --filter testDumpJSONLCorpus
```

## Итог

| | |
|---|---:|
| Записей в корпусе | 1096 |
| Записей изменено | 328 (29.9%) |
| Всего замен | 551 |
| Уникальных пар | 144 |

Удалений и вставок слов нет ни одного — нормализатор только заменяет.

Пар, меняющих число слов: **0**. Сравнение идёт по кускам, разделённым пробелом,
а не по «словам», — иначе `сонетагента` → `Sonnet-агента` записалось бы как
`Sonnet агента` и пунктуационная регрессия осталась бы невидимой, ради чего снапшот
и заводился (замечание код-ревью 2026-07-27).
