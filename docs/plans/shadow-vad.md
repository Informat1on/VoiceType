# B3 — теневой VAD и детектор повторов (только измерение)

Дата: 2026-09-24. Ветка `feat/reliable-dictation` (HEAD `359f0cb`). Дорожная карта — этап 2
«инструменты качества», пункт B3 (B1 replay и B2 Eval — `docs/plans/quality-tools.md`).

## 1. Цель

Измерить на сохранённых записях истории, дали бы VAD-предфильтр (Silero и энергетический
гейт) и детектор повторов пользу, **не меняя продовый путь** (запись → распознавание →
пост-обработка → вставка). Результат — отчёт агрегатами, лист кандидатов для ручной
разметки владельцем и решение по каждому механизму с числами (§8). Само включение в прод —
отдельной задачей, только для доказавшего пользу.

## 2. Ограничения

- `Sources/` не меняется. Ни одной строки продового кода.
- Приватность — как у replay (`quality-tools.md` §6): по умолчанию только агрегаты. Тексты
  речи — только с `--include-private-text`, и только в файл `--out` вне рабочего дерева
  репозитория, права 0600. В stdout тексты не печатаются никогда.
- Python — только стандартная библиотека (numpy нет в системе; остальные скрипты так же).
- Сборка харнесса — только через `scripts/replay.sh` (`--build-system native`, иначе
  whisper в тестовом процессе даёт мусор).
- Пороги klava (RMS 0,005, Silero 0,3) не принимаются на веру — перебираются сеткой.

## 3. Инструменты (установлено разведкой 24.09)

- Silero VAD: `/opt/homebrew/bin/whisper-vad-speech-segments` (whisper.cpp 1.9.4, Homebrew).
  Вызов: `whisper-vad-speech-segments -vm <модель> -vt <порог> -f <wav>`. stdout:
  `Speech segment <i>: start = <X>, end = <Y>` — **X, Y в сотых долях секунды** (проверено:
  `Tests/Fixtures/bench/01.wav` 5,40 с → `start = 93.00, end = 541.00`). stderr — шум
  инициализации Metal. CAF не читает (`failed to read audio data`) — нужен WAV.
- Модель: `~/.cache/voicetype/ggml-silero-v6.2.0.bin`, 885 098 байт, sha256
  `2aa269b785eeb53a82983a20501ddf7c1d9c48e33ab63a41391ac6c9f7fb6987`
  (источник `huggingface.co/ggml-org/whisper-vad`).
- Конвертация: `afconvert -f WAVE -d LEI16@16000 -c 1 <in.caf> <out.wav>` (записи уже
  16 кГц mono Int16).

### T2. `scripts/shadow-analysis.py`

CLI:
```
scripts/shadow-analysis.py <replay.jsonl>
    [--audio-dir DIR]          # по умолчанию: history-режим → ~/Library/Application Support/VoiceType/audio;
                               # dir-режим → обязателен
    [--vad-model PATH]         # по умолчанию ~/.cache/voicetype/ggml-silero-v6.2.0.bin
    [--vad-thresholds 0.3,0.5] [--rms-gates 0.002,0.005,0.01]
    [--silence-overlap 0.2]    # сегмент whisper «в тишине», если доля его длительности,
                               # покрытая речью Silero (порог 0.5), меньше этого значения
    [--include-private-text] [--out FILE]
```
Режим (`history`/`dir`) — из строки `run` JSONL. Загрузка — переиспользовать `load_replay`
и `index_by_key` из `scripts/replay-compare.py` через `importlib.util.spec_from_file_location`
(имя файла с дефисом), не копировать. Они бросают `SystemExit(<сообщение>)` — перехватить и
выйти с кодом 2 (сообщения содержат только путь и ключ, не текст речи).

**Входная валидация (fail-closed, иначе exit 2):** дубликаты ключей (`index_by_key`);
`summary.records` ≠ числу строк `record`; `summary.errors` ≠ числу записей с `error`.
Записи с `error` не анализируются и считаются в шапке отдельно (`replayErrors`); если
`replayErrors > 0` — exit 1 после печати отчёта.

**Покрытие (fail-closed).** Счётчики в шапке: `selected` (все записи), `noAudioField`
(`audioFile` отсутствует/`null` — в истории это запись без сохранённого аудио),
`replayErrors`, `analyzed`. Запись с `audioFile`, чей файл не найден в `--audio-dir`, —
**ошибка анализа** (exit 1), а не пропуск. `analyzed == 0` → exit 2. Знаменатель всех долей —
`analyzed` (печатать его рядом с каждой долей: «7/64 (10,9 %)»).

**Когорты.** Все агрегаты — отдельно по двум когортам: `current` (`comparableToHistory ==
true`, либо dir-режим) и `legacy` (остальные), плюс строка «итого». Выводы о включении —
только по `current`.

Для каждой проанализированной записи:
1. **Декод.** `afconvert -f WAVE -d LEI16@16000 -c 1` во временный каталог
   `tempfile.mkdtemp()` (0700), удаление в `finally` (и при исключении, и при Ctrl-C).
2. **Энергия** (stdlib `wave` + `array('h')`): кадры 20 мс, RMS в шкале [0,1]. На запись:
   RMS всей записи, p95 и max кадрового RMS.
3. **Silero** для каждого порога из `--vad-thresholds`: интервалы речи (мс). Ненулевой код
   утилиты, пустой stdout без строки `Detected N speech segments` или строка сегмента не по
   формату, или число распарсенных сегментов ≠ N → ошибка анализа записи. Из записи
   вычисляется **доля речи** (сумма интервалов / длительность) и тишина в начале/конце.
4. **Сегменты whisper** (`segments[{text,startMs,endMs}]` — сырые, до фильтра): для
   каждого — длительность, доля перекрытия с речью Silero **при каждом пороге VAD**;
   `inSilence(t)`, если доля < `--silence-overlap`; `beyondAudio`, если
   `endMs > audioSeconds*1000 + 100`; позиция `first`/`last`/`middle` (единственный сегмент —
   `first` и `last`).
5. **Какие сегменты снял фильтр — репликой правила фильтра, со сверкой.** Скрипт
   повторяет `HallucinationFilter.split` в точности (`Sources/VoiceType/Services/
   HallucinationFilter.swift:76–99`, `normalize` — `:101–126`): те же шаблоны
   (`templates`, `:44–55`, скопировать дословно с комментарием-ссылкой), та же нормализация
   фильтра (схлопнуть пробельные, снять хвостовые `.…!?`, trim, lower — **не** нормализация
   детектора повторов из п.6), та же логика: `isTemplate` по каждому сегменту, длина ведущей
   и хвостовой серий, при `keepStart >= keepEnd` сняты все. Итог — множество **позиций**
   снятых сегментов. Сверка: тексты снятых позиций в порядке `префикс + суффикс` обязаны
   побайтно совпасть с `removedTemplates` записи; не совпало → ошибка анализа записи
   (ловит и дрейф списка шаблонов относительно кода).
6. **Детектор повторов** (нормализация: нижний регистр, `ё→е`, пунктуация → пробел,
   схлопнуть пробелы). Все флаги — **кандидаты на разметку**, не подтверждённые галлюцинации:
   - `dupSegment` — соседние сегменты с равным нормализованным непустым текстом; в отчёте
     отдельно: оба сегмента из 1 токена («Да. Да.») и из ≥ 2 токенов;
   - `loop` — внутри нормализованного `raw`: n-грамма (n = 2…6 токенов) подряд ≥ 3 раз,
     либо один токен подряд ≥ 4 раз;
   - `edgeTemplate` — первый/последний сегмент равен одному из кандидатов. Два списка,
     в отчёте раздельно: **строгий** — шаблоны фильтра из п.5 (приведённые к нормализации
     п.6) плюс `спасибо за просмотр`;
     **рискованный** (встречается в настоящей речи, фильтр их сознательно не трогает) —
     `спасибо`, `спасибо за внимание`, `подписывайтесь на канал`. Для каждого — снят ли
     этот сегмент фильтром (по позициям из п.5).
7. **Симуляции (без изменения прода).** Смысл чисел — «изменился бы **нынешний** вывод
   `final`», а не «потеряна произнесённая речь»; так и подписывать в отчёте.
   - энергетический гейт: для каждого порога из `--rms-gates` — записи с RMS записи < порога;
     разбивка: `final` непуст / `final` пуст из-за фильтра (`removedTemplates` непуст) /
     `final` пуст по другой причине;
   - гейт Silero «нет речи»: для каждого порога VAD — записи с нулём интервалов, та же
     разбивка.

**Отчёт (stdout, только агрегаты, по когортам):**
- шапка: путь утилиты, путь и sha256 модели Silero, mode, pipelineStamp, счётчики покрытия;
- доля речи в записях: min/p5/p50/p95; тишина в начале и в конце: p50/p95 (мс); RMS записи:
  min/p5/p50/p95;
- **главная таблица ТЗ** (доли от `analyzed` когорты): записи хотя бы с одним `dupSegment`
  / `loop` / `edgeTemplate`-строгий / `edgeTemplate`-рискованный / сегментом `inSilence(t)`
  для каждого t / `beyondAudio`; для каждой строки, кроме `loop`, — сколько из этих записей
  фильтр уже исправил (хотя бы один флагованный сегмент снят по п.5). Для `loop` (ищется в
  `raw`, не привязан к сегменту) столбец — `n/a`;
- перекрёсток: флаги повторов × `inSilence(0.5)`; `inSilence` по позиции first/last/middle
  и по длительности сегмента (< 1 с / ≥ 1 с);
- чувствительность: число сегментов `inSilence` при `--silence-overlap` 0.1/0.2/0.5 для
  каждого порога VAD (одна маленькая таблица);
- симуляции (п.7);
- записи с эталоном (`reference`): только их число.

**Приватный режим** (`--include-private-text`, **требует** `--out`, иначе exit 2). Путь
`--out` сначала канонизируется `Path(out).expanduser().resolve()` (снимает симлинки), и
**канонический** путь проверяется `inside_repository` из `replay-compare.py`
(переиспользовать) и им же открывается на запись; внутри рабочего дерева — отказ, exit 2.
Файл создаётся с правами 0600. лист разметки — по
каждой записи с хотя бы одним флагом или `inSilence(0.5)`: key, когорта, длительность, RMS,
интервалы Silero (0.5), сегменты (текст, время, перекрытие, флаги, снят ли фильтром),
`final`, `reference` (если есть), и пустая колонка «метка владельца». В stdout в этом режиме —
те же агрегаты, тексты только в файл.

**Язык отчёта.** Все подписи stdout/stderr — ASCII (английские, как в `replay-compare.py`),
чтобы любая кириллица в выводе была признаком утечки (см. DoD п.4). Пути (модель, утилита)
и имена файлов в stdout/stderr печатаются через `ascii()` (не-ASCII — `\u`-экранами), так что
вывод целиком ASCII независимо от путей.

**Диагностика без текста.** Сообщения об ошибках анализа содержат только key, имя файла,
стадию и код возврата внешней программы. stdout/stderr `afconvert` и утилиты VAD в
диагностику не пересказываются (там только шум Metal, но правило — не печатать чужой вывод).

**Код выхода:** 0 — все выбранные записи проанализированы (кроме `noAudioField`), ошибок 0;
1 — хотя бы одна ошибка анализа или `replayErrors > 0` (отчёт всё равно печатается, числа в
шапке); 2 — ошибка аргументов/входа (нет модели, нет утилиты, невалидный JSONL, запрет
приватного режима, `analyzed == 0`).

- реплика фильтра по позициям: префикс, суффикс, оба;

  `summary.records` не сходится → exit 2; дубликат ключа → exit 2;

  (а) обычная — уникальный маркер (`PRIVMARK<n>`, кириллический вариант `ПРИВМЕТКА<n>`) в
  `raw`, `final`, каждом `segments[].text`, `reference`, `history.raw`, `history.text`;
  (б) запись, где все сегменты — дословный шаблон фильтра (`Продолжение следует.`), поэтому
  `removedTemplates` = эти тексты, `final` пуст; маркеры — в `reference`, `history.*`;
  (в) запись с маркерами в полях и `audioFile`, чей файл отсутствует (ошибка анализа).
  Прогон `main()` в обычном режиме и в приватном с `--out` во временный файл → ни stdout, ни
  stderr не содержат `PRIVMARK`, `ПРИВМЕТКА`, `Продолжение следует` (ни в каком регистре) и
  ни одного кириллического символа; приватный файл содержит маркеры и имеет права 0600;
- `--include-private-text` без `--out` → exit 2; `--out` внутри репозитория → exit 2;
  `--out` — путь вне репозитория, являющийся симлинком на файл внутри него → exit 2, файл
  не создан/не изменён;
- реплика фильтра: одинаковый текст-шаблон на краю (снят) и в середине (сохранён) — снята
  только краевая позиция; все сегменты — шаблоны → сняты все; расхождение реплики с
  `removedTemplates` → ошибка.

Запуск: `python3 -m unittest discover -s scripts/tests -v`.

## 7. Риски

- Утилита Homebrew (whisper.cpp 1.9.4) ≠ ревизия форка — для измерения VAD неважно (модель
  Silero та же), но фиксируем путь и sha256 модели в шапке отчёта.
- Калибровка на одном микрофоне (Wave XLR MK.2) — выводы не переносить на другие входы.
- Разметки мало (2 сохранённые eval-записи) — поэтому приватный лист для ручной разметки.
- Время: 100 записей × (afconvert + запуск утилиты × число порогов) — ожидается < 2 мин;
  если больше — сообщить, не оптимизировать заранее.
- Первые записи истории — со старым промптом: все агрегаты по когортам `current`/`legacy`,
  выводы — только по `current`.
